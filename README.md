# Carlucci'sHome per iOS

App iOS nativa che contiene Carlucci'sHome (gestione documenti personali).

- Ogni push su `main` compila l'IPA su GitHub Actions e la pubblica nelle **Releases**.
- Installa `CarlucciHome.ipa` sull'iPhone con **Sideloadly** (Apple ID gratuito: va rinnovata ogni 7 giorni).

Per aggiornare l'app: sostituisci `CarlucciHome/Web/index.html` e fai push.
